# 소리가치 공공기관 구독형 카테고리 — 프로토타입 전달 패키지

- 발주사: 주식회사 스캣업 (소리가치 운영)
- 수행사: 클라우드시프트
- 과업명: 공공기관 구독형 카테고리 개발
- 전달일: 2026.11.06

## 1. 전달 내용 (스캣업 제공)

스캣업이 제작한 **화면 프로토타입(정적 HTML)** 입니다. 소리가치 홈페이지·관리자 페이지의 디자인 시스템(색상·서체·아이콘·레이아웃)을 그대로 따르고 있으며, 수행사는 본 프로토타입을 기준으로 실제 서비스에 구현합니다.

```
gov-subscription/
├─ pages/
│  ├─ category.html        # 기관 구독 카테고리 소개 (요금제·혜택·도입 절차)
│  ├─ apply.html           # 구독 신청 폼 (기관 정보·담당자·요금제·인원)
│  ├─ success.html         # 신청 완료 안내
│  └─ admin/
│     ├─ list.html         # [관리자] 기관 구독 신청 목록 (검색·상태 필터)
│     └─ manage.html       # [관리자] 기관 구독 상세·상태 관리
├─ screenshots/            # 위 5개 화면 캡처 (참고용)
└─ README.md
```

### 디자인 토큰
| 항목 | 값 |
|---|---|
| Primary | #2E6FE6 (hover/dark #1E55C0) |
| Text (ink) | #16233D |

각 HTML은 외부 의존성 없이 브라우저에서 바로 열립니다(폰트만 Google Fonts 로드).

## 2. 수행사 구현 범위 (과업지시서 기준)

1. **프론트엔드 통합**
   - 위 5개 화면을 소리가치 프론트엔드(www.sorigachi.co.kr) 및 관리자 페이지 코드베이스에 컴포넌트로 이식
   - 메인 GNB에 "기관 구독" 메뉴 추가, 관리자 사이드바에 "기관 구독 관리" 메뉴 추가
   - 반응형(모바일/태블릿/PC) 대응 및 크로스브라우저 QA
2. **백엔드 API / DB**
   - 구독 신청 저장: `POST /api/gov-subscription` (기관명·기관유형·담당자·연락처·이메일·요금제·인원·요청사항)
   - 관리자 목록·상세·상태 변경: `GET /api/admin/gov-subscription`, `GET …/{id}`, `PATCH …/{id}/status`
   - 상태값: 접수 / 검토중 / 계약진행 / 구독중 / 종료
   - DB 테이블 설계 및 마이그레이션 (gov_subscription, gov_subscription_log)
3. **알림**
   - 신청 접수 시 관리자 이메일(또는 알림톡) 발송, 신청자에게 접수 확인 메일 발송
4. **권한**
   - 관리자 화면은 기존 관리자 계정 체계와 연동(로그인·권한 체크)
5. **배포**
   - 스테이징 검수 후 운영 배포
