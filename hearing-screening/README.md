- 전달일: 2026.11.06

## 1. 전달 내용 (스캣업 제공)

스캣업이 제작한 **청각 스크리닝 PoC(단일 HTML)** 입니다. Web Audio API 기반으로 동작하는 측정 로직과 화면 흐름이 모두 포함되어 있으며, 수행사는 본 PoC를 기준으로 소리가치 서비스에 정식 기능으로 구현합니다.

```
hearing-screening/
├─ demo/
│  └─ index.html     # PoC 전체 (측정 로직·화면·결과 차트 포함, 브라우저에서 바로 실행)
└─ README.md
```

### PoC 포함 기능
- **순음청력검사(PTA)**: 250~8,000Hz 주파수별 좌/우 역치 측정, 오디오그램(canvas) 출력
- **소음 속 숫자 인지검사(DIN)**: 배경소음 하 숫자 3자리 청취 → 정답률·SNR 산출
- **결과 화면**: 좌/우 청력 등급 판정, 결과 카드, 보청기 상담 연결 CTA
- 헤드폰 캘리브레이션 안내, 진행 단계 표시

### 디자인 토큰 (소리가치 공통)
Primary #2E6FE6 / Ink #16233D / BG #F5F7FB / Line #E4EAF3 / Pretendard → Noto Sans KR

## 2. 수행사 구현 범위 (과업지시서 기준)

1. **프론트엔드 통합**
   - PoC의 측정 모듈(pta / din / audio / scoring)을 분리하여 소리가치 프론트엔드에 컴포넌트로 이식
   - 소리가치 디자인 시스템 적용, 모바일(iOS Safari / Android Chrome) 오디오 재생 정책 대응
   - 음량 캘리브레이션 및 기기별 보정 로직 보강
2. **백엔드 API / DB**
   - 측정 결과 저장: `POST /api/hearing-test` (사용자ID·일시·주파수별 역치·DIN 점수·판정)
   - 결과 이력 조회: `GET /api/hearing-test?userId=`
   - 관리자 "보청기 현황/설문 현황"과 연계되는 측정 결과 조회 화면
3. **회원/권한 연동**
   - 기존 소리가치 회원 로그인과 연동, 비회원 측정 시 결과 임시 저장 후 가입 유도
4. **결과 활용**
   - 측정 결과 기반 보청기 견적 요청·예약 화면으로 연결
5. **배포**
   - 스테이징 검수 후 운영 배포
